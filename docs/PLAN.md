# Implementation Plan: Livestream Donation System

This plan is split into smaller documents to make it easier to target specific sections (both for humans and LLM workflows).

## How to Use This Plan

- For day-to-day “what’s next” and what’s already implemented, start with [PROGRESS.md](PROGRESS.md).
- For design and system constraints, treat [PRD.md](PRD.md) and [ARCHITECTURE.md](ARCHITECTURE.md) as the source of truth.
- For execution, use the task list and checkpoints in [plans/tasks.md](plans/tasks.md).

## Plan Documents

- [plans/context.md](plans/context.md): overview, locked decisions, integration notes, and dependency graph
- [plans/tasks.md](plans/tasks.md): the full task list with acceptance criteria and verification steps
- [plans/roadmap.md](plans/roadmap.md): parallelization notes and suggested handoff order
- [plans/risks.md](plans/risks.md): risks, mitigations, and open questions
