# Product

## Register

product

## Users

### Viewer (Donor)
Livestream viewers who want to support their favorite creator with a monetary tip and a custom message. They pay quickly on mobile or desktop without creating an account.

### Streamer (Host)
Content creators who showcase real-time alerts on stream to build community engagement and manage/replay donations.

## Product Purpose

Donatex is a self-hosted, single-user livestream donation system for the Indonesian payment ecosystem. It handles dynamic QRIS generation (via Mayar API) and displays real-time sequential OBS alerts on confirmed payments.

## Brand Personality

- **Developer-Console & Livestream-Native**: Tech-forward, terminal-inspired aesthetic utilizing vivid cyan/sky-blue and purple accents, structured as clean, high-contrast overlay alerts.
- **Structured & Minimalist**: Engaging layout using monospace details, pill-shaped social badges, and smooth transitions that command attention without cluttering.
- **Earned Trust**: Fast, functional, and highly reliable.

## Anti-references

- SaaS-cream interfaces (generic soft blue/grey dashboards).
- Left-stripe or right-stripe card accents.
- Gradient text and overly blurred default glassmorphism.
- Modal-first interactions where inline options fit better.
- Identical card grids repeated endlessly.
- Decorative motion that doesn't convey state or celebration.

## Design Principles

1. **Celebratory Visibility**: Make every donation feel like an event on stream via vibrant neon cues and synced canvas confetti.
2. **Friction-Free Flow**: Optimize for instant payments (preset amounts, no registration, quick QRIS scan).
3. **Robust Durability**: Prioritize database persistence before any broadcast to ensure alerts are never lost.
4. **Focused Simplicity**: Keep the interface clean, functional, and centered on the donation task.

## Accessibility & Inclusion

- High contrast text on dark backgrounds to ensure readability.
- Clear, distinct focus rings for keyboard navigation.
- Accommodate screen readers on donor and admin routes.
