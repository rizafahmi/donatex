# Deterministic sync for donor Presence lifecycle tests

**Category:** bug
**Status:** done
**Source:** `.claude/plans/donor-visitor-presence/reviews/donor-visitor-presence-review.md`

## Summary

Donor Presence lifecycle tests wait until the test process receives a PubSub `presence_diff`, then immediately assert each LiveView’s render. Because the test process and LiveViews are independent subscribers, receipt by one process does not prove every target LiveView has processed its copy, so assertions can race.
